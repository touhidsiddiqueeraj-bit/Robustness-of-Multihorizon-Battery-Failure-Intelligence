Laboratory validation is not field validation

The published multihorizon hazard model was trained and tested on clean laboratory data: full cycles, fixed C-rates, controlled temperatures.

Real battery operation is different:

  • Partial cycling — varying depths of discharge
  • Temperature fluctuations — sensor noise, thermal gradients
  • Irregular rest periods — variable idle between cycles

Does calibration survive when the model meets real conditions?

2 / 11
Our approach

Systematic robustness test across four severity levels

Perturb laboratory data → apply frozen model → measure calibration degradation → test recalibration
3 / 11

Perturbation methodology

Raw NASA discharge curves are truncated at random depths of discharge, Gaussian temperature noise is added, and proportional rest noise is applied to duration and temperature.

Root cause: minimum voltage shift

The primary driver is a shift in the minimum voltage feature:

2.3 V
Full discharge
3.2 V
75% DoD truncation

A 39% increase. The XGBoost model learned split thresholds on clean feature ranges; the isotonic calibrator cannot adapt to the shifted probability distribution.

9 / 11

Practical deployment path

  1. 1. Deploy the frozen XGBoost model as-is
  2. 2. Collect 50–100 operational cycles during normal BESS operation
  3. 3. Fit a new isotonic regression on these cycles
  4. 4. Deploy the recalibrated model — no base classifier retraining needed

No original training data required • No additional feature engineering

10 / 11
Conclusion

Calibration is fragile. Recalibration is practical.

Multihorizon hazard models are not inherently robust to operational distribution shift,
but a lightweight recalibration step suffices for field deployment.
